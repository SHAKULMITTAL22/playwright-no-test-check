# Submit a Single Transfer Between Accounts

> **Status**: Preview — awaiting worker execution for full scenario details

## Overview

| Field | Value |
|-------|-------|
| Workflow ID | WF001 |
| Feature Area | Transfer Funds Workflow |
| Priority | high |
| Goal | Successfully transfer funds between Checking and Saving accounts using the Make a Transfer form. Ensure confirmation and correct entry in transfer history. |

## Navigation Hint

1. Navigate to https://www.ngpf.org/bank-sim
2. Click 'GET STARTED NOW' on the landing page
3. Click 'Ok' to dismiss onboarding modal
4. Expand sidebar menu 'TRANSFERS' by clicking expand_more
5. Click 'MAKE A TRANSFER'
6. Select 'SINGLE' in PAYMENT FREQUENCY dropdown
7. Select 'CHECKING ($216.04)' in Transfer From dropdown
8. Select 'SAVING ($230.00)' in Transfer To dropdown
9. Enter '50' in $ Amount field
10. Select today's date in Payment Date field
11. Click 'Save'
12. Observe green snackbar 'Amount has been transferred to Saving Account'
13. Confirm new entry appears in Past Transfers table with correct Id, Date, Description, Amount
