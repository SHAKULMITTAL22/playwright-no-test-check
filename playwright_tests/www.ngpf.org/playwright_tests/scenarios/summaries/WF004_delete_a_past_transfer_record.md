## Navigation Hint

1. Navigate to https://www.ngpf.org/bank-sim
2. Click 'GET STARTED NOW'
3. Click 'Ok'
4. Expand sidebar 'TRANSFERS' and click 'DISPLAY ALL TRANSFERS'
5. Locate desired transfer row in Past Transfers table
6. Click trash/delete icon in Actions column for row
7. Confirm the record is removed from table; observe confirmation message if shown
