# Filter and Search Transfer History Records

> **Status**: Preview — awaiting worker execution for full scenario details

## Overview

| Field | Value |
|-------|-------|
| Workflow ID | WF003 |
| Feature Area | Transfer History and Management |
| Priority | medium |
| Goal | Filter and search completed/scheduled transfers by account, date, and description. Validate table updates correctly and empty states are handled when filters are too restrictive. |

## Navigation Hint

1. Navigate to https://www.ngpf.org/bank-sim
2. Click 'GET STARTED NOW'
3. Click 'Ok'
4. Expand 'TRANSFERS' sidebar and click 'DISPLAY ALL TRANSFERS'
5. Click 'Checking' or 'Saving' above Past Transfers to filter by account
6. Enter keywords (e.g., '03/22/2026', 'Transfer') in Search field to filter by date or description
7. Observe table displays only matching records; if filters exclude all data, table shows '0 of 0' and disables management actions
