## Navigation Hint

1. Navigate to https://www.ngpf.org/bank-sim/home
2. Click 'MANAGE RECIPIENT' in the sidebar
3. Click '+ ADD RECIPIENT', enter name, and click 'SUBMIT'
4. Navigate to 'PAY BILL'
5. Select 'SINGLE' frequency, select the new recipient, enter amount, and click 'SUBMIT'
6. Navigate to 'DISPLAY ALL BILLS' to verify the transaction
