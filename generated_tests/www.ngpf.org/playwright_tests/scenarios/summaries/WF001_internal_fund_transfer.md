## Navigation Hint

1. Navigate to https://www.ngpf.org/bank-sim/transfer
2. Select 'SINGLE' from 'Payment Frequency'
3. Select 'CHECKING' from 'Transfer From'
4. Select 'SAVING' from 'Transfer To'
5. Input '10.00' into 'Amount'
6. Input '03/30/2026' into 'Date'
7. Click 'Save'
8. Navigate to 'Display All Transfers' to verify the transaction.
