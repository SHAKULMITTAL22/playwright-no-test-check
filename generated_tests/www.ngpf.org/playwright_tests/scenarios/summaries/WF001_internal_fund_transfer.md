## Navigation Hint

1. Navigate to https://www.ngpf.org/bank-sim/transfer
2. Click 'TRANSFERS' in the sidebar
3. Click 'MAKE A TRANSFER'
4. Select 'SINGLE' frequency
5. Select source account (e.g., 'CHECKING')
6. Select destination account (e.g., 'SAVING')
7. Enter amount and click 'Save'
8. Navigate to 'DISPLAY ALL TRANSFERS' to verify the entry.
